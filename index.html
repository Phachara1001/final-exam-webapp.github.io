ระบบบันทึกรายรับ-รายจ่าย (Income & Expense Tracker)

ให้นักศึกษาพัฒนาระบบบันทึกรายรับ-รายจ่ายอย่างง่าย โดยประยุกต์ใช้เทคโนโลยีที่ได้เรียนมา ได้แก่ Vue.js สำหรับจัดการฝั่ง Frontend, Tailwind CSS สำหรับตกแต่งความสวยงามของหน้าจอ และ Supabase สำหรับจัดการฐานข้อมูล (Database)

Vue.js Tailwind CSS Supabase

สร้างฐานข้อมูลด้วย Supabase

  • ✓
    สร้าง Project ใหม่บน Supabase
  • ✓
    สร้าง Table ชื่อ transactions โดยมีโครงสร้างดังนี้:
    Name Type Default Value / Options
    id uuid Primary Key (PK)
    type text เก็บค่า 'income' หรือ 'expense'
    title text -
    amount numeric -
    created_at timestamp default: now()
    คำอธิบายฟิลด์ข้อมูล:
    • id: รหัสประจำรายการ (อ้างอิงอัตโนมัติไม่ซ้ำกัน)
    • type: ประเภทของรายการ เก็บค่าเป็น 'income' (รายรับ) หรือ 'expense' (รายจ่าย) เท่านั้น
    • title: ชื่อหรือรายละเอียดของรายการ (เช่น เงินเดือน, ค่าไฟ)
    • amount: จำนวนเงิน
    • created_at: วันที่และเวลาที่บันทึกรายการ (ระบบจัดการให้อัตโนมัติ)
  • ✓
    สำคัญมาก อย่าลืม ปิด RLS (Disable Row Level Security) หรือตั้งค่า Policy ให้สามารถ Insert/Select/Delete ได้แบบ Public

ตั้งค่าโปรเจกต์ Vue.js และตกแต่ง UI

  • ✓
    สร้างโปรเจกต์ Vue.js ใหม่ (แนะนำให้ใช้ Vite)
  • ✓
    ติดตั้งและตั้งค่า Tailwind CSS ให้พร้อมใช้งาน
    • ติดตั้งโดยใช้คำสั่ง npm install tailwindcss @tailwindcss/vite
    • ตั้งค่าใน vite.config.js และ style.css ให้ถูกต้อง
  • ✓
    ติดตั้ง @supabase/supabase-js และเขียนโค้ดเชื่อมต่อ (Client) ใน Vue
    • สร้างไฟล์ .env กำหนดค่าให้ถูกต้อง
    • สร้างไฟล์ supabase.js ให้ถูกต้อง
  • ✓
    สร้างองค์ประกอบต่างๆให้สวยงาม โดยแบ่งเป็น 3 Component แล้วนำมาแสดงผลรวมกันที่ App.vue ประกอบด้วย:
    • Dashboard.vue (แสดงยอดรวมรายรับ, ยอดรวมรายจ่าย, ยอดคงเหลือ)
    • TransactionForm.vue (ฟอร์มสำหรับเลือกประเภท รับ/จ่าย, กรอกชื่อรายการ, และจำนวนเงิน)
    • TransactionList.vue (ตารางหรือรายการแสดงประวัติการทำรายการ)
